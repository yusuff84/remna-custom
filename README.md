# TOP VPN — Кастомная страница подписки Remnawave

Кастомизированная и оптимизированная страница подписки (Subscription Page) для панели **Remnawave** с фирменным брендингом **TOP VPN**, поддержкой клиентов **INCY** и **Happ**, а также ультра-простым и интуитивным интерфейсом для мобильных и десктопных устройств.

---

## 🚀 Особенности и изменения

1. **Фирменный стиль TOP VPN**:
   * Глубокая полуночно-синяя тема (`#040914` / `#050B14`) с мягкими неоновыми световыми акцентами.
   * Фирменный векторный знак спидометра в шапке и динамическое название бренда (подтягивается из конфига Remnawave).
   * Цветной мобильный статус-бар (`theme-color: #040914`).
   * Кнопка смены языка перенесена в верхнюю панель управления.

2. **Компактная строка информации на первом экране**:
   * Оставлены только две самые важные для клиента метрики:
     * **Срок действия** (дата окончания подписки).
     * **Трафик** (использованный объем / лимит с тонким прогресс-баром).
   * На телефонах и компьютерах карточки компактно занимают одну строку (~48px высоты).
   * Убраны громоздкие старые блоки и радужные рамки.

3. **Мгновенный ключ подписки (Quick Key)**:
   * Ссылка на ключ выведена прямо на первом экране.
   * Кнопка **«Скопировать»** в один клик с виброоткликом и уведомлением.
   * Кнопка **«QR-код»** для быстрого сканирования камерой телефона.

4. **Интерактивный пошаговый мастер подключения**:
   * Автоматически определяет устройство клиента (iOS, Android, Windows, macOS, Linux).
   * Центральный вопрос: **«Установлено у вас одно из приложений? Если да — выберите его и нажмите «Да»»**.
   * Карточки двух избранных приложений: **INCY** (слева) и **Happ** (справа).
   * **Если клиент нажал «НЕТ, СКАЧАТЬ»**:
     * Открывается экран загрузки для конкретно выбранного приложения (прямые ссылки в App Store / Google Play / на установщик).
     * После установки нажимается кнопка **«Я СКАЧАЛ»**.
   * **Если клиент нажал «ДА» или «Я СКАЧАЛ»**:
     * Появляется большая главная кнопка **«ПОДКЛЮЧИТЬ ВПН»**, которая открывает deep-link (`incy://add/...` или `happ://add/...`), импортирует подписку в один клик и копирует ключ в буфер.
     * Предусмотрена кнопка «← Выбрать другое приложение» для возврата.

## 🛠️ Локальная разработка и тестирование (с мок-данными)

### 1. Установка зависимостей
```bash
cd frontend
npm install --cache /tmp/.npm-cache
```

### 2. Генерация мок-данных
Скрипт синхронизирует локальный `.env` и конфиг `frontend/public/assets/.app-config-v2.json` с вашим реальным файлом `subpage-00000000-0000-0000-0000-000000000000.json`:
```bash
npm run mock:gen
```

### 3. Запуск сервера разработки
```bash
npm run start:dev
```
Сервер запустится по адресу: **http://localhost:3334/** с поддержкой HMR (изменения применяются мгновенно без перезагрузки).

## 🐳 Сборка своего Docker-образа и деплой на сервер

На сервере Remnawave стандартно запущен готовый образ `remnawave/subscription-page:latest`. Для применения нашего кастома собирается собственный Docker image.

### Шаг 1. Сборка продакшен-бандла фронтенда
```bash
cd frontend
npm run start:build
cd ..
```
*(Создаст папку `frontend/dist`, которая вшивается внутрь Docker-образа).*

### Шаг 2. Сборка Docker-образа
```bash
docker build -t top-connected/subscription-page:custom .
```
*(Или укажите ваш тег в Docker Hub / GitHub Packages, например: `yusuff84/subscription-page:custom`).*

### Шаг 3. Публикация в Registry (если собираете на локальном ПК)
```bash
docker push top-connected/subscription-page:custom
```
*(Если собираете сразу на боевом сервере в отдельной папке `/opt/remna-custom`, загружать в реестр не обязательно — образ сразу будет доступен локально в Docker).*

### Шаг 4. Подключение в docker-compose на сервере
В файле `/opt/remnawave/docker-compose.yml` найдите сервис `remnawave-subscription-page` и замените `image`:

```yaml
  remnawave-subscription-page:
    image: top-connected/subscription-page:custom
    # остальное оставляем без изменений (порты, переменные окружения и т.д.)
```

### Шаг 5. Перезапуск контейнера
```bash
cd /opt/remnawave
docker compose up -d remnawave-subscription-page
```

### 🔄 Откат назад (если потребуется)
Чтобы вернуть стандартную страницу подписки Remnawave:
```yaml
  remnawave-subscription-page:
    image: remnawave/subscription-page:latest
```
и выполните:
```bash
docker compose up -d remnawave-subscription-page
```
